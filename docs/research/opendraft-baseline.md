## Interchange verification gates

The OpenDraft manual describes conversions that can flatten structure or change element types. Treat each format and fixture as a separate result. A file produced by SWDR verifies its own round trip. A synthetic fixture based on public source verifies that source mapping. Genuine permitted releases are needed to verify interoperability with a third-party exporter. [OpenDraft format compatibility](https://proteus-technologies-private-limited.github.io/OpenDraft/user-manual/format-compatibility.html)

| Format or path | Current OpenDraft evidence | Required fixture and pass condition |
| --- | --- | --- |
| `.odraft` | Pinned v1 and v2 envelope and optional assets read from source | Open both source-conforming variants and a genuine v2.13.0 export. Compare typed content, title, assets and AV fields. Report omitted or unsupported stores. |
| FDX, Fountain and DOCX | Published element and title mappings with format-specific losses | Export a synthetic two-scene script from the pinned app with title fields, scene numbers and dual dialogue. Verify source presentation, editable values and explicit loss reporting. |
| Text, RTF and PDF | Text and PDF paths are documented. DOCX and plain text remain usable conversion routes for unsupported proprietary inputs. | Keep an unsupported or malformed input intact and route it to an editable file. Verify text-layer PDF, mixed pages, image-only and protected samples, including page counts and editable re-export guidance. |
| AV CSV, XLSX and YAML | The manual describes spreadsheet output plus structured YAML, which retains more AV properties | Export the 60-second and 20-minute AV examples. Compare row order, typed columns, explicit cues and attachments or report omissions. |
| `.celtx` / `.cxscript`, `.wdz`, `.sbx`, `.fadein`, `.osf` | OpenDraft documents import-only `.celtx` and `.wdz`. It flags `.wdz` as experimental and says a genuine WriterDuet export had yet to be verified. It describes Fade In and Open Screenplay Format layout mappings. | Each extension stays pending for SWDR until one genuine permitted export is obtained and validated. Verify maintained source links and list field and pagination losses before marking it supported. |

Baseline boot and synthetic keyboard writing were verified on the exact release. The subsequent AV and export command returned HTTP `410 sandbox_stopped` when the session expired. AV timing, relationship edits, history restore, offline reconnect, actual co-writing and genuine third-party format exports remain separate runtime checks.
