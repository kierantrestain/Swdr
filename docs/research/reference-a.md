## WriterDuet

| Check | Walkthrough steps and documented behaviour | SWDR decision | Pass condition |
| --- | --- | --- | --- |
| WD-01 Two writers and scope | Invite a reader or writer and open the same project. Co-writing shows collaborator presence and cursor location. The documented sharing options include reading, writing and sharing. [Co-writing](https://www.writerduet.com/article/416-a-guide-to-effortless-co-writing-in-writerduet) · [Sharing](https://www.writerduet.com/article/149-invite-collaborators-to-a-project) | Authorise reads and mutations per project and episode, including presence, downloads and search. | Two authenticated writers edit different blocks, then the same block, and converge across two sessions. Revoke a writer and verify the next read, write and presence sync fail. A scoped user only receives their authorised episode. |
| WD-02 Anchored comments and revisions | Open the line margin, add and reply to a comment. In Accept/Reject, filter changes by author and step through the diff. Accept keeps the change, reject removes it. [Comments](https://www.writerduet.com/article/221-comments) · [Accept or reject](https://www.writerduet.com/article/108-review-accept-collaborator-changes) | Anchor conversations and suggestions to stable blocks and revision IDs. Keep acceptance and rejection attributable. | A reviewer comments and suggests a replacement on one line. A writer accepts one change and rejects another. Reorder scenes and confirm each thread still opens the intended block. |
| WD-03 Line history | Open the line’s revision history, select a previous version and revert. The text on the page returns to that earlier value. [Line history and revert](https://www.writerduet.com/article/104-revert-line-to-previous-draft) | Record the restore as a new head operation with the original author and revision still retained in history. | Edit a line three times, restore the initial text and reopen the project. Verify the initial value is current and all three edits remain in history. |
| WD-04 Offline and reconnect | Disconnect from the network and keep working. WriterDuet documents distinct unsaved, saved-on-device and synced states and local storage across a normal restart on the same profile. [Offline writing](https://www.writerduet.com/article/234-write-offline) | Persist queued operations before announcing local durability. Report server acknowledgement separately. | Disconnect one of two writers, edit a line, restart the tab/browser and recover the pending version, then reconnect. Both sessions converge and the sync acknowledgement changes only after the server accepts the operation. |
| WD-05 Interchange and archive | Open File, then Export, and choose the output format and document set. FDX and Fountain appear alongside WDZ, where the default includes all project documents. PDF can select and preserve page numbering. [Export walkthrough](https://www.writerduet.com/article/261-export-a-document) | Preserve a file-format capability matrix. Keep WDZ pending until a genuine permitted file passes import validation. Provide SWDR archives covering the whole project. | Export FDX and Fountain and reopen the named fixtures. For a genuine WDZ, first report the detected project contents and validate actual preservation before enabling it in the supported-format list. Restore a SWDR archive in a clean workspace and resolve every fixture asset and revision link. |
